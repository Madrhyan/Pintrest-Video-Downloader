# 📌 Pinterest Video Downloader (via GitHub Actions)

A powerful tool to download multiple Pinterest videos at once using GitHub Actions.

## 🚀 نحوه استفاده

این پروژه به شما اجازه می‌دهد چندین ویدیوی پینترست را به صورت هم‌زمان از طریق GitHub Actions دانلود کنید.

### 🛠 مراحل اجرا:

1. **مرحله اول: داشتن حساب کاربری**
   حتماً باید یک حساب کاربری در GitHub داشته باشید.

2. **مرحله دوم: فورک کردن پروژه (Fork)**
   روی دکمه **"Fork"** در بالای سمت راست صفحه کلیک کنید تا یک کپی از این پروژه در حساب خودتان ساخته شود.

3. **مرحله سوم: اجرای عملیات (Run Workflow)**
   - در ریپازاتوری خودتان، به تب **"Actions"** بروید.
   - از لیست سمت چپ، نام ورک‌فلو (Workflow) را انتخاب کنید.
   - روی دکمه **"Run workflow"** کلیک کنید.
   - **نکته بسیار مهم:** می‌توانید چندین لینک ویدیو را وارد کنید، اما حتماً بین هر لینک یک فاصله (Space)** قرار دهید.

## 🇺🇸 English Instructions

A simple tool to download multiple Pinterest videos using GitHub Actions.

1. **Step 1: Account Required**  
   Make sure you have a valid GitHub account.
2. **Step 2: Fork this Repository**  
   Click the **"Fork"** button at the top right to create a copy in your account.
3. **Step 3: Run Workflow**  
   - Go to the **"Actions"** tab in your forked repository.
   - Select the workflow from the left sidebar.
   - Click on **"Run workflow"**.
   - **Important:** You can provide multiple video links; just ensure there is a space** between each link.
